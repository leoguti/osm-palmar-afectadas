# Construcciones afectadas — Terremoto San José del Palmar (2026-08-10)

`palmar_afectadas.geojson` — puntos de las construcciones mapeadas en OpenStreetMap como
afectadas por el sismo del Palmar (`damage:event=2026ColombiaEarthquake-Palmar`,
Wikidata Q140984463). Pensado para consumir como **datos remotos** en uMap.

Se actualiza periódicamente desde la API de Overpass.
